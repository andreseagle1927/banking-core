# Service contracts

Versioned API and event contracts are published here. The [public OpenAPI spec](openapi/public-api.yaml) documents the implemented transfer and notification APIs; the [TransferCompleted v1 schema](schemas/transfer-completed-v1.schema.json) defines the event consumed by Notification Service. Do not share service persistence models as contracts. Ledger's internal development endpoints are documented in [the architecture overview](../docs/architecture/overview.md).
